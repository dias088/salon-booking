# Скриншоты для README

Снимать на демо-данных после `make seed` — тогда календарь и статистика
заполнены.

| Файл | Что на нём | Как получить |
|---|---|---|
| `home.png` | главная с популярными услугами | `/` |
| `booking-wizard.png` | шаг выбора времени с сеткой слотов | `/booking`, дойти до третьего шага |
| `my-appointments.png` | «Мои записи» с кнопкой отмены | войти как `client@salon.dev`, `/my` |
| `admin-calendar.png` | календарь дня: колонки мастеров, блоки по статусам | войти как `admin@salon.dev`, `/admin`, выбрать завтрашний день |
| `admin-stats.png` | графики выручки и загрузки | `/admin/stats` |
| `master-schedule.png` | расписание мастера на неделю | войти как `aigerim@salon.dev`, `/master`, вкладка «Неделя» |

Ширина окна 1280 px для десктопных экранов; для `booking-wizard.png` имеет
смысл снять ещё и мобильную версию — клиентская часть делалась в первую
очередь под телефон.
